# 早晚报导读与图片工具

双击项目根目录的 **启动导读图片工具.vbs**。不需要打开终端，不需要每天把报表发送给助手。

1. 点击“加载最新早报／晚报”，或导入 TXT、Markdown 文件，也可直接粘贴全文。
2. 核对类型、日期及正文。无法识别日期时手动填写 `YYYY-MM-DD`；时间可留空，不会猜成当前时间。
3. 目标图片数默认6张，建议4—6张，可自行修改。点击“生成导读和图片”，查看百分比、分页及逐张生成进度；完成后显示100%、成功说明及弹窗，再点击“复制导读”和“打开成品文件夹”。

默认输出到 `D:\HousingBot\分享输出\2026-10-23早报`，里面只有 `导读.txt` 和 `01.png` 等完整分页图片。先发导读，再按编号选图。图片宽1080像素，高度自动在1920—4320之间调整，正文保持34像素字号；优先通过加长图片达到目标张数，不缩小字号，不删减业务内容。达到最长画布后仍放不下时，完整输出实际张数，并明确提示超出目标。

工具去掉网址、链接编号和单独的原文链接标签，保留有实质内容的链接标题。导读只引用输入中的统计，不推断资格或成功概率。导入文件支持 UTF-8、带BOM的UTF-16及GB18030。若正文只有月日而没有年份，需要手动补全日期。

相同正文、日期、类型、时间和排版设置重复生成时，校验并复用已有成品，不新增版本。可识别的“群发、账号、发送时间＋重复标题”平台包装自动去掉；Markdown链接与复制后的链接标签、空白及时间秒数不会被误判为业务更新。内容、目标张数或实际排版变化，以及已存在成品被手工修改时，保存为“第2版”等新目录，不覆盖旧文件；完成提示会说明复用或另存原因。修改输入后需重新点击生成，再复制新导读。

本机加载只读取已经接口受理的正式冻结报表，不重新采集，不连接发送接口，不占定时推送日键。加载到的晚报可能是前一天，日期以窗口显示为准。工具只排版输入信息，不修正其业务数据。

内部校验记录及错误日志在 `data/share-tool/`，临时排版文件生成结束后清理。旧的多格式分享包保留，新工具不使用那个输出目录。依赖现有虚拟环境、Tkinter和本机Chrome；无需上传CloudBase。
