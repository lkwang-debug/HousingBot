## 接口

均使用 `Authorization: Bearer <当天凭证>`，每次校验HMAC-SHA256签名、生效时刻、失效时刻及用途。

- `POST /session`：服务端时间、到期时间、已发布版本及地区/队列目录。
- `POST /query`：只接收 `region`、`apply_no`、`queue`、`version`，返回本次编号命中的记录、排位及必要分析上下文。全量编号、其他家庭正式排序及完整顺序数组不返回。
- 所有数据响应禁止缓存。无效/过期凭证返回401，版本不匹配409，非法参数400。跨域预检由CloudBase网关统一处理，函数继续校验准确页面来源；避免重复的Allow-Origin响应头导致浏览器拒绝请求。
- 网页保留本人队列选择、多轮记录、竞争统计和情景演算。家庭人数、孩子数量、意向选择在浏览器计算，不上传接口。

## 后续名单更新

完整名单变更后仍先在本地构建核对；签名模式自动将构建输出转到非公开目录。仅上传静态页面已经不能更新云端查询资料，必须成对发布函数私有包和页面。

在 `D:\HousingBot` 下执行构建，使用新的、不存在的输出目录：

```powershell
.\.venv\Scripts\python.exe -m tools.secure_lookup build --output D:/HousingBot-release/新的版本目录 --api https://hzk-283347622-d2gko9gqw36b68830-1511821740.ap-shanghai.app.tcloudbase.com/housing-query --origin https://szbaozufang.cn
```

确认本地预览及统计无误后，使用已登录的CloudBase CLI更新代码，保留现有函数环境变量及网关配置：

```powershell
npm exec --yes --package @cloudbase/cli@3.8.9 -- tcb fn code update housing-lookup --dir D:/HousingBot-release/新的版本目录/function --deployMode cos --json -e hzk-283347622-d2gko9gqw36b68830
npm exec --yes --package @cloudbase/cli@3.8.9 -- tcb hosting deploy D:/HousingBot-release/新的版本目录/static hzktest --verify --json -e hzk-283347622-d2gko9gqw36b68830
.\.venv\Scripts\python.exe -m tools.secure_lookup verify --release D:/HousingBot-release/新的版本目录
.\.venv\Scripts\python.exe -m tools.verify_signed_online_browser --output docs/report-previews/新的验收目录
.\.venv\Scripts\python.exe -m tools.secure_lookup activate --release D:/HousingBot-release/新的版本目录
```

`activate`会重新校验线上文件、所有地区真实编号、跨域预检、凭证拒绝和本地来源版本，再登记发布；更新本地页面和配置时持有跨进程锁。原 `lookup-publish` 在签名模式下拒绝登记未经云端校验的版本。

失败时保留上一套已验证的签名版本，或提示维护；不要将含完整公开名单的旧静态页面重新发布。备份目录 `D:\HousingBot-backups\20261026-151235-signed-lookup` 仅供本地恢复与核对。
