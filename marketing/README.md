# 抖音图文卡片

日常早晚报转小红书群，请使用新版[导读图片工具](../docs/导读图片工具.md)：双击项目根目录“启动导读图片工具.vbs”，成品只有导读和编号图片，支持加载本机报表、导入文件和粘贴正文。

小红书群的完整日报分享使用独立的[分享包导出流程](../docs/小红书群分享包.md)：从已受理的正式冻结报表导出分页图片、导读和分条原文链接，不使用下面的营销精选图替代全文。

8 张 1080×1440 竖图，按文件名顺序发到抖音「图文」。

## 生成

```powershell
python marketing/make_cards.py
```

输出在 `marketing/out/`：`01-cover.png` … `08-how.png`，同目录的 `.html` 是排版源文件，改字改色直接改 HTML 后重跑即可。

## 卡片顺序

| 文件 | 内容 | 配图 |
|---|---|---|
| 01-cover | 封面：每天两条不漏一批 + 四条推送时间线 | 排版 |
| 02-instant | 新通告，官网发出半小时内到 | 排版（模拟推送） |
| 03-digest | 每日早报 08:30，一屏看完今天能报什么 | 真实早报截图 |
| 04-evening | 每日晚报 20:30，白天漏掉的晚上补一遍 | 真实晚报截图 |
| 05-remind | 截止前 3 天 / 1 天各提醒一次 | 排版（模拟推送） |
| 06-lookup | 认租编号查队列和排位 | 真实查询结果截图 |
| 07-districts | 七个区都能查 | 真实区列表截图 |
| 08-how | 三步用法 + 隐私说明 | 排版 |

## 换成新截图

截图丢进 `marketing/assets/`，文件名见该目录的 README（`digest.png` = 早报、`evening.png` = 晚报、`lookup.png` = 查询结果、`index.png` = 区列表、`instant.png` / `remind.png` = 新通告 / 截止提醒），重跑脚本即可，外框和标题不变。

早报、晚报都是长截图，要先裁：早报留到「近 24 小时」那行，晚报留到「需要关注 · 坪山」那行，底部做一段渐变淡出，否则塞不进一页。

## 发之前的注意事项

- 每页底部都带「公开信息整理 · 非官方账号」，别去掉——深圳对保障房自媒体的表述有明确要求，不冒用官方名义是底线。
- 图里出现的所有数字（套数、户数、截止时间）都来自库里的真实通告，换新一批发之前先跑一次更新，别用过期数字。
- 截图里不要出现认租编号、姓名、证件号。`lookup.png` 是从「查一下」按钮下面开始裁的，就是为了把输入框里的编号裁掉。
- 06 页写的是「前面两个队列已经占满」，不要改成「肯定没戏」或「大概率能中」之类的承诺。
